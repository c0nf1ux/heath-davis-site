# heath-davis-site

Personal landing page. Static site built on the Prologue template (HTML5 UP,
CC BY 3.0), with real content wired in: no mock data, no placeholder copy.

Deployed via Vercel on push to `main`.

## Structure

- `index.html` - all page content
- `assets/` - template CSS/JS, unmodified except for content edits inside `index.html`
- `images/avatar.jpg` - headshot (replace with the real file before deploying)
- `images/banner.jpg` - template background texture, kept as-is

## Local preview

Open `index.html` directly in a browser, or serve the directory with any
static file server.
